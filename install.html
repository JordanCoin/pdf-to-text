Use with your AI agent

One command installs the extraction engine and drops a skill where your agent looks for it. Everything runs locally.


  


  
What it installs

  
    
    
  • ~/.pdf-to-text/bin/pdf-to-text: the native engine (3 MB) plus an open-source font pack (24 MB) for glyph fingerprint matching. Checksum verified.
    • 
    
  • A SKILL.md in each selected agent's skill folder, so the agent knows when and how to call it.
    • 
  


  
Claude Code plugin (optional)

/plugin install pdf-to-text@JordanCoin/pdf-to-text
